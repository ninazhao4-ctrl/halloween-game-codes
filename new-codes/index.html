How We Verify New Codes

A code is listed only after there is enough evidence to describe it accurately.

  • Check whether the code comes from an official game channel or verifiable in-game source.
  • Confirm the exact spelling and whether a redemption feature exists.
  • Record only rewards that can be verified; unknown rewards stay unknown.
  • Move codes out of the active list when expiration is confirmed.

Redeem a Cosmetic Code

  1. Update the game and open Graveyard.
  2. Choose Extras, then Redeem Codes.
  3. Enter your personal code and select Redeem.

Patch 1.0.2 fixed the controller Redeem button. Check your promotion email for restrictions if the code still fails. Steam game keys use Steam's activation process instead.
